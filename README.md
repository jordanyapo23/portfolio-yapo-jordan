# Yapo Jordan - Portfolio

Portfolio personnel de Yapo Jordan, étudiant en Licence 2 de génie logiciel à l’Institut Ivoirien de Technologie.

## Technologies

- HTML, CSS et Bootstrap
- JavaScript organisé en modèle, vue et contrôleur (MVC)
- CV consultable dans `cv.html` et téléchargeable depuis la page

## Projets présentés

- VoisinApp
- Scraper Amazon
- Analyse comparative de marché

Le site est conçu pour être publié comme site statique GitHub Pages.
